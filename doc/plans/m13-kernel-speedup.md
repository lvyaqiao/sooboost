# m13-kernel-speedup.md 内核级提速：填充热路径访存优化

> 类型：T1 变体（方案 = 契约候选）｜提出者：master 域｜状态：已立项，待维护者批准开工
> 立项依据：2026-09-01 瓶颈黑盒探针（`tmp/bottleneck-probe/`，探针脚本与结果不入仓）+ M9/M10/M11 实证
> 关联：doc/ledgers/roadmap.md M13 行；红线 3（确定性）/红线 6（测试面）/红线 7（unsafe 审查）

## 1. 背景（全部为实测，非推断）

- 填充主导已双重实证：M9 单趟填充 +13~34%、M10 直方图减法 −27%；M11 给扫描加预存净亏 4.8%。
- 探针 A（california d6，median of 3 warm）：bins 255/64/16 → 0.710/0.767/0.743s，**耗时与 bins 无关**（扫描族份额低于噪声）→ 一切扫描侧优化（含向量化扫描）收益上限 ≈ 0。
- 探针 B（XGBoost 同实现 A/B）：lossguide（leaf-wise）比 depthwise（level-wise）**慢 1.75×** → leaf-wise 生长不是免费杠杆，排除。
- 探针 C：sooboost d5→d6 仅 +1.3% 耗时（min_samples_leaf=5 已天然剪枝）→ level-wise 层级结构健康，无可观无效填充。
- 冷/热口径：compare_giants 冷跑 california 1.54s vs 探针 warm 0.71s；对 LightGBM 真实差距 warm 口径 ≈ 2.4×（0.71 vs 0.30）。

**结论**：与 LightGBM 的剩余差距在填充内核的访存效率（SIMD 直方图、缓存利用率、线程调度），不在算法结构。

## 2. 目标与非目标

**目标**：warm 口径 california A/B 实测提速，分 tranche 推进、每 tranche 独立验收：
- T1 缓存分块调优：行主序路行块（row block）大小/对齐调优，消除 false sharing（块边界对齐缓存行）。
- T2 填充内循环访存压缩：评估 per-row (bin, g, h) 读放大，评估 `grad`/`hess` 合并布局（SoA→AoS 或反之，以实测为准）。
- T3 EFB 式特征捆绑（仅当探针证明划算）：先测三真实集特征互斥率/稀疏度，互斥率低则本 tranche 直接关闭不实现。

**非目标（显式排除，防止重试同方向）**：
- 任何扫描侧优化（探针 A 证伪收益；M11 tot 预存禁止重试）
- leaf-wise / 生长策略改动（探针 B 证伪）
- bins 缩减（探针 A 证伪且掉精度）
- 手写 SIMD intrinsics / 新依赖（红线 7 + AGENTS.md 依赖克制；SIMD 内核留远期行）
- 精度妥协：**任何改动必须逐位恢复 v0.2.0 基线**（0.8403341506124684 / 0.3876609594474578 / 0.9950396825396826）

## 3. 确定性约束（红线 3，每 tranche 强制）

- 块划分、seed 选择、归并顺序只依赖数据形状，不依赖线程数/负载。
- 累加顺序不得改变：M11 实证行序重排即翻转近平局分裂（breast_cancer AUC 0.9950→0.9931）。T2 若改布局，只改**读取方式**，不改**求和顺序**。
- 验证：任意线程数序列化字节逐位一致 + 三集指标与 v0.2.0 基线逐位相等。

## 4. 测量方法学（M9/M11 两次教训固化）

- 结论只能来自**同轮交替 A/B**（新旧二进制交替、best-of-N）；跨轮绝对值不可比。
- 多线程噪声大时用 `RAYON_NUM_THREADS=1` 聚焦（红线 3 保证单线程=多线程结果）。
- warm 口径为准（先空跑预热），冷启动数字单独标注。

## 5. 验收标准

- workspace 127+ 测试全绿、fmt/clippy `-D warnings` 干净、三道基准门禁全过。
- 每 tranche 有同轮交替 A/B 记录；无实测收益或净回归的 tranche 整体回退并落档（对齐 M11 负结果纪律）。
- 模型格式 v4 零变更（纯内核改动，序列化字节不受影响）。

## 6. 风险

- T2 布局改动可能触碰累加顺序 → 违反者即时回退，不等 tranche 结束。
- T3 若真实集互斥率高但捆绑改变 bin 表布局，需验证逐位一致后才可实现；不可实现则降级为「仅记录探针结论」。
- 并行会话风险：立项时工作树存在未提交的 sooboost-ffi/ 改动（另一会话），实现须待其收口后基于干净树开工。
