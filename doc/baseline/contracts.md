## 一、契约

### 1.1 数据契约（红线 1、2 落地）

- arrow `RecordBatch` 是**核心内存表示**；Parquet/Polars/DuckDB 数据在布局兼容时零拷贝进入，布局不兼容时只允许**一次**显式转换（转换路径可测量、有记录，禁止隐式多级拷贝）；parquet 零拷贝进入是 M0 可测量目标，不承诺所有数据源零拷贝。
- 缺失值语义唯一定义：arrow null 位图 = 缺失；NaN 是否视为缺失由训练配置决定，一旦确定全库一致，任何模块不得自行解释。
- 类别列必须以 `DictionaryArray` 进入；OOV（训练未见类别）、UTF-8、nullable 类别三条边界行为必须显式定义（见 AGENTS.md §易踩坑 4）。
- schema 校验：列名/类型/类别映射不一致时**必须显式报错**，禁止静默降级。

### 1.2 模型格式契约（红线 5 落地）

- 模型文件以版本头开头；结构为：版本头 + 模型头 + 树数组 + bin 表 + loss 配置 + 元数据。
- 格式演进必须显式升版本；禁止"读老版本时静默猜"。
- 序列化/反序列化错误必须显式传播（Result），禁止忽略或截断（对治 CatBoost 零拷贝加载静默损坏）。
- 热替换（Arc 原子 swap）的模型必须自包含（含 bin 表），加载即校验完整。
- **字节布局显式规格**（不依赖 serde/bincode/postcard 默认布局，序列化实现须按本规格显式写出）：endian 统一小端；浮点/整数宽度按字段固定并记录在模型头；数组元素宽度显式；对齐规则显式；checksum（尾部或边带，加载时校验）；长度/偏移越界校验。
- **语义规格**：缺失值默认方向（缺失样本走左/右子树，模型头记录）；categorical split 编码方式（bin id 集合的编码约定）；模型损坏时返回显式错误类型（区分"版本不支持 / checksum 失败 / 结构非法"）。
- 热替换选型：std `Arc` 无 `swap` 方法（2026-08-19 勘误），单写者发布场景用 `RwLock<Arc<..>>`（读锁仅覆盖 Arc 克隆，预测本体无锁，见 sooboost-core/src/model/hot_swap.rs）；读重场景再评估 `arc-swap`（RCU 等价物），不预埋。

### 1.3 内部不变量（红线 3 落地）

- 相同输入 + 相同种子 → 模型与预测逐位一致（与线程数无关）。
- 并行聚合顺序确定（排序后归约），浮点中间量规则见 AGENTS.md §易踩坑 6。
- 该不变量必须写成确定性测试入 CI，任何精度改动须先跑过它。

### 1.4 类别特征契约（M1 期，D9 落地）

- 训练期字典统一：`DictionaryArray` 的字典在训练期显式构建为跨 batch 统一字典；不一致时显式报错，禁止静默合并。
- OOV 编码：训练未见类别（推断期出现的新值）映射到专用 OOV bin——不崩溃、行为可预测、有文档；推断期与训练期行为一致。
- null 与字符串类别区分：arrow null 位图 = 缺失，与任何字符串值不混淆；null 类别走缺失值语义（红线 2），有独立 bin。
- 防泄漏：ordered target statistics 的样本序由训练 seed 决定的 permutation 派生（仿 CatBoost），禁止使用全量 target 均值；smoothing 参数默认值写入契约，训练配置可覆盖。
- 高基数上限：类别 bin 数显式上限，超限报错（报错而非静默截断）。

### 1.5 C ABI 契约（远期，预留位）

- 将来暴露 C ABI 时：符号命名空间稳定、错误码语义固定、资源生命周期（create/free 配对）契约先行定义；绑定层不得反过来影响核心架构（红线之外的软性约定，详见 AGENTS.md §易踩坑 7）。
