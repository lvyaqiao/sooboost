## 1. 目标

在 M0 已验证的最小闭环（arrow 数据层 + Loss trait + 确定性直方图 + GBDT 训练）之上，
补齐核心功能面与工程化能力。M0 的九项承诺继续生效（回归不破坏）。

## 2. 五项工作流（缺一不可，按 tranche 分批执行）

| # | 工作流 | 契约/决策承接 | 风险 | 验收方式 |
|---|---|---|---|---|
| M1-1 | **模型序列化/热替换** | D6 + contracts §1.2 字节布局显式规格（版本头 + 模型头 + 树数组 + bin 表 + loss 配置 + 元数据） | 低（已完全规格化） | 快照回归：save→load→逐位一致；版本头/checksum/越界错误显式；`Arc::swap` 热替换 |
| M1-2 | **D8 其余目标函数** | D8：回归 L1/quantile/huber/poisson/gamma/tweedie + 多分类 + 排序 | 中 | 每个新 Loss 数值梯度/海森 proptest + 端到端训练改善；多分类输出矩阵 |
| M1-3 | **rayon 并行（直方图/分裂搜索）** | D2 泛型组合（并行 = 新增 trait 实现，零工厂）+ 红线 3 层级二（并行聚合顺序确定） | 中高（确定性是硬约束） | 并行/串行结果逐位一致测试入 CI；基准门禁收益验证 |
| M1-4 | **类别特征 ordered TS** | D9 + contracts §1.4（统一字典/OOV/null 区分/防泄漏/高基数上限） | 高（易踩坑 4） | OOV/UTF-8/nullable/高基数四类边界显式测试；防泄漏测试（不用全量 target 均值） |
| M1-5 | **基准门禁** | AGENTS §测试纪律「基准门禁」列 | 低 | bench CI 纳入训练/推理性能回归门禁（并行/M1-3 的收益守护） |

## 3. 红线与易踩坑承接

- **红线 3 层级二**：并行聚合顺序确定（排序后归约）；确定性测试入 CI（与线程数无关逐位一致）。
- **红线 6 操作化**：M1-1 模型格式改动 → 快照回归；M1-4 读入外部字节（类别）→ fuzz 补位。
- **易踩坑 4**：类别特征 OOV/UTF-8/nullable/高基数四类边界必须显式测试。
- **易踩坑 6**：加权/quantile 聚合中间量 f64。
- **易踩坑 10**：反序列化错误显式传播，禁止 unwrap 于库代码。
- **红线 4**：一切运行时状态经 TrainingContext；并行后仍零全局可变状态。

## 4. 测试面（入 CI）

| 类别 | 内容 |
|---|---|
| 快照回归 | 模型序列化/反序列化兼容（canondata 思路）；save→load→预测逐位一致 |
| 确定性 | 并行/串行训练逐位一致（红线 3 层级二）；并行聚合顺序确定 |
| 属性测试 | 新 Loss 数值梯度/海森；类别 OOV 不崩溃且行为可预测 |
| fuzz | 模型字节解析路径（M1-1）；类别字典/高基数边界（M1-4） |
| 基准门禁 | 训练/推理性能不回归（M1-3 收益守护） |
| 集成 | 训练→序列化→反序列化→预测 端到端回路 |

## 5. 明确不做（M1 边界）

- 权重、group/排序（M1-2 的排序工作流若排期靠后可顺延至 M2）
- SIMD、GPU（M2+）
- EFB/GOSS（D9：专利规避 + 纯 CPU 收益有限）
- 自定义 Loss 运行时注册（M2 再评估）
- C ABI / pyo3（远期）

## 6. 收口条件

五项工作流全绿 + 快照回归/并行确定性/fuzz 入 CI + 基准门禁达标 → 状态标 ✅，M2 立项。
