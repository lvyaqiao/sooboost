## 区段规则（写者必读）

1. **只追加不改旧**：已交付条目只允许补记（手动验收结果），禁止改写历史决策/动作/验证
2. **条目模板**：`### <日期> <主题>` + 决策（为什么）/ 动作（改了什么）/ 验证（测试与门禁证据）/ 待手动验收
3. **待办区**：域 owner 执行视图，条目必须带 backlog/roadmap 引用行号（`[B-01]` / `[M0]`）——无引用 = 未立项
4. **跨域声明**：动他人域文件前投 doc/roles/mailbox/ 对应收件箱（投递即完成，不等批复）
5. **共享面/契约变更**：写者在自己域文件记录 + shared.md 登记一行（维护者汇总）

## 对齐规则（整体 ↔ 个人）

1. **权威单点**：状态只在 doc/ledgers/roadmap.md 变迁（维护者维护）；本目录文件是执行视图
2. **完成判定**：个人文件标"已完成"不算数——roadmap 状态变 ✅ + 合入 master 才算
3. **引用铁律**：待办条目必须带行号引用，只存在于个人文件的条目视为未立项
4. **冲突**：个人计划与整体排期冲突 → 维护者仲裁

## 归档触发器

- **里程碑结束**：该里程碑相关域条目区段移 doc/archive/（登记 archive/README）
- **收口流程**：维护者在里程碑收口时统一执行，域 owner 不自行归档
