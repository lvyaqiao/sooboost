## 规则

1. **投递即完成声明**：动他人域文件前，向对应收件箱投一条，**不等批复即可开工**；合入提交/交付记录附声明链接。无需逐文件打招呼——一次特性一条
2. **条目格式**：`日期 | 特性分支 | 触碰文件清单 | 预期改动 | 合入提交（收口人合入后补）`，投递人自行追加表格行
3. **闭环**：条目关联收口人的 merge 合入，合入 master 即销号（状态列标 ✅）；收件人可回「认领」或「异议」（理由），异议上维护者裁决
4. **共享可写**：本目录是 doc/roles/ 的唯一共享例外，全员可写；不收私人日志（私人日志仍进各人子目录）
5. **不投信箱的**：共享面/契约变更仍在 doc/records/shared.md 登记一行；人员级事项仍登记 doc/ledgers/roadmap.md
6. **与 taskbox 正交**：任务分派走 doc/roles/taskbox/（单向、维护者独占写）；本箱只收「动他人文件的声明」
