## 诚实的边界（不随好消息消失）

1. 对标用统一预算（200 轮 / lr 0.1 / seed 42），**非逐库调参最优成绩**；结论限定「同一梯队」而非领先。
2. 速度慢于 LightGBM/XGBoost（SIMD / leaf-wise 差距）——已定位为 M6 性能门禁方向。
3. 门面暂不覆盖多分类（`MulticlassBooster` 仍需直调）；早停 / 交叉验证 / 特征重要度**均未实现**。
4. benchmark 环境锁定 managed venv（numpy/pandas/sklearn/xgboost/lightgbm/catboost），CI 中 Python 门禁依赖 `requirements.txt`。

## 下一步：M6 立项建议（顺序即优先级）

1. **早停 + K 折 CV**——可用性最大缺口，直接影响真实使用体验。
2. **特征重要度**（gain/cover）——模型解释的基础。
3. **多分类硬化 + 校准**——补齐门面覆盖。
4. **性能门禁**——把 california 上 vs LightGBM 的训练速度差距纳入 CI 追踪（先测量再优化，防止性能回归不可见）。
